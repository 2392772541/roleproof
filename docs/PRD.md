# RoleProof 职证台产品需求文档（PRD）

- 版本：v0.1 Demo / Rule Mode
- 日期：2026-09-04
- 产品定位：面向中国 AI 产品经理的求职情报与项目证据工作台

## 1. 问题

现有求职工具通常把 JD 匹配压缩成一个不可解释的百分比，再生成一段无法核验的简历文案。用户不知道：哪条岗位要求被覆盖、证据是什么、哪些内容只是模型推测、还缺什么材料。

## 2. 核心主张

> 让每一个岗位匹配结论，都能被你的真实项目证明。

产品完整闭环：职位情报 → JD 结构化 → 要求与证据匹配 → 人工确认 → 定制作品集 → 面试准备 → 面试复盘 → 证据库更新。

## 3. 目标用户

- 需要展示 AI 项目、但缺少组织方法的 AI 产品经理求职者。
- 从传统产品、运营或数据岗位转向 AI 产品方向的人。
- 需要针对不同岗位快速调整案例顺序和表达重点的人。

## 4. 核心页面

1. **Intelligence**：保存职位来源、JD 原文、阶段和匹配概览。
2. **Job Detail**：把 JD 拆为硬性要求、AI 能力、产品能力、职责、行业和加分项。
3. **Job × Evidence**：逐条展示匹配证据、强度、理由、缺口和人工决定。
4. **Evidence Library**：保存项目角色、真实行动、结果、指标和材料链接。
5. **Portfolio Studio**：根据岗位重排项目，但只能引用合法 Evidence ID。
6. **Interview Review**：保存问题、真实回答、证据、薄弱点和补强行动。

## 5. 非目标

- 不做批量自动投递。
- 不爬取需要登录或禁止自动化的平台。
- 不替用户捏造经历、指标或项目成果。
- 不把 AI 建议自动写入用户主档案。

## 6. MVP 验收

- 无 API Key 可走完所有页面和闭环。
- JD 原文及来源可保留，规则引擎可重新解析。
- 每个匹配引用的 Evidence ID 必须真实存在。
- 五项子分之和严格等于总分。
- 生成段落默认 Pending，支持接受、编辑和驳回。
- 不同岗位可生成不同项目顺序。
- 面试问题绑定证据，用户回答不能由系统伪造。
- 工作区支持 JSON 导入和导出。
