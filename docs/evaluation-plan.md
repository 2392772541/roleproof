# 评估方案

## 1. JD 解析

建立至少 100 条中文 AI 产品岗位要求测试集，标注类型、关键词和是否硬性要求。

- 分类准确率
- 硬性要求召回率
- 重复要求合并准确率

## 2. 证据匹配

每条岗位要求由两名人工判断是否能被指定项目直接证明。

- Top-1 相关率
- 无证据时正确拒绝率
- Evidence ID 合法率（目标 100%）
- 人工接受率、编辑率、驳回率

## 3. 内容生成

- 事实一致性
- 证据引用正确率
- 不支持陈述率
- 不同岗位项目排序差异

## 4. 产品效果

- 完成一份岗位定制作品集所需时间
- 面试准备覆盖的岗位要求比例
- 每次复盘新增或补强的证据数量
- 7 日和 30 日留存

## 5. 当前自动化测试

- JD 能拆成结构化 Requirement。
- 所有匹配引用均为合法 Evidence ID。
- 五项子分之和严格等于总分且不超过 100。
- 没有匹配证据时返回明确缺口，不强行推荐。
