# 竞品调研摘要

调研日期：2026-09-04。

## 商业产品能力分布

Teal、Huntr、Simplify、Jobscan、Careerflow、Jobright、Rezi、Kickresume、Final Round AI 和 LoopCV 已覆盖职位追踪、简历优化、JD 匹配、申请自动化或面试练习。

## 开源能力分布

JobOps、Resume Matcher、Reactive Resume、JobSpy、OpenResume、CareerTrack、OSApplyTrack、JobHunt、Job Tracker 和 CareerSync 主要覆盖职位采集、ATS 匹配、简历编辑和申请看板。

## 可借鉴

- 职位 Kanban 和状态追踪。
- JD 与简历的结构化比较。
- 本地优先、可导入导出。
- 简历和案例的岗位定制版本。

## RoleProof 差异化

市场常见链路是 `JD → 简历文本`，RoleProof 聚焦尚未被完整连接的链路：

```text
JD → Requirement → Evidence → Project Story → Portfolio → Interview Answer
```

核心资产不是生成文本，而是用户可持续积累、核验和复用的项目证据图谱与人工决策记录。
